# Клиент универсального фреймворка

Перед изменениями прочитай [общие правила](../AGENTS.md),
[соглашения frontend](../docs/frontend.md) и при изменении входа —
[авторизацию](../docs/authentication.md). Команды запуска и проверок находятся в [README](../README.md).

- Компоненты — Vue Options API с `defineComponent`, `data`, `computed`, `methods` и lifecycle.
  Не используй `<script setup>` или Composition API для логики компонентов.
- Pinia stores описывай через `state/getters/actions`, подключай `mapState` и `mapActions`.
- Порядок SFC: `template`, `script lang="ts"`, `style lang="scss" scoped`.
- Страницы лежат в `src/components/<entity>`, общие элементы — в `src/components/ui`.
  Не добавляй обязательные слои и подпапки для каждого экрана.
- HTTP-запросы выполняет явно импортируемый типизированный `request` из `src/mixin/fetch.ts`.
  Компоненты не собирают cookie/JWT и не хранят токены в localStorage.
- Backend-контракты допустимы только как `import type` из публичных `*Types.ts`.
  Серверные сервисы, репозитории, Fastify и Prisma не попадают в клиентскую сборку.
- SCSS компонента вложен в корневой класс. Состояния — через `&`, дочерние селекторы — внутри родителя.
  Два пробела, каждое свойство на отдельной строке; не уплотняй блоки в одну строку.
- `responsive($max-width)` располагается внутри изменяемого селектора рядом с обычными свойствами.
  Не собирай адаптивность отдельным повторным деревом в конце файла.
- Общие переменные и миксины — `assets/css/common.scss`, подключение — Sass `@use`.
  Цвета компонентов — общие переменные или именованные CSS-цвета, без hex.
- Поля и кнопки используют общие стили из `assets/css/style.scss` и UI-компонентов.
  На странице описывай layout, не копии оформления `input`, `label`, `select`, `textarea`.
- Используй минимальные семантические DOM-узлы. Обёртке нужна причина в семантике или layout.
  Не удаляй доступные подписи, focus и сообщения об ошибках ради сокращения разметки.
- Логические поля используют `BoolInput`. Подтверждения оформляй компонентами, без `alert/confirm/prompt`.
- Полные понятные имена важнее сокращений. Не добавляй CSS-фреймворк, неявные mixins или изменения прототипов.

Из корня запускай `npm run check:client`; из `client` — `npm run check`.
Проверка включает Vue TypeScript, соглашения компонентов и стилей, тесты и сборку.
При изменении UI проверь desktop и узкий экран, клавиатуру и отсутствие горизонтального скролла.
При изменении авторизации проверь login/logout, обновление защищённого маршрута и истечение сессии.
